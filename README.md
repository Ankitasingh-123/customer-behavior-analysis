# 📊 Customer Behavior Dashboard (Power BI)

## 📖 Overview
This project presents a **Customer Behavior Analysis Dashboard** built using **Microsoft Power BI**.  
The dashboard provides insights into customer purchasing patterns, spending behavior, and key business metrics to support data-driven decision-making.

---

## 🎯 Objectives
- Analyze customer purchasing trends
- Identify high-value customers
- Understand sales distribution across categories
- Track revenue and transaction performance
- Generate actionable business insights

---

## 🛠️ Tools & Technologies Used
- **Power BI (.pbix)**
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)
- Excel / CSV Dataset (Customer Shopping Behavior Data)
